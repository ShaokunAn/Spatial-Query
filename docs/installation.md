# Installation

## Requirements

- Python >= 3.10
- A C++ compiler (for the bundled C++ extension)

## Install via pip

```bash
pip install SpatialQuery
```

## Dependencies

SpatialQuery requires the following packages (installed automatically):

- `anndata>=0.8.0`
- `pandas>=2.0.3`
- `scipy`
- `matplotlib>=3.7.5`
- `mlxtend>=0.23.1`
- `seaborn>=0.13.2`
- `scikit-learn>=1.3.2`
- `statsmodels>=0.14.0`
- `scanpy>=1.9.5`
- `pybind11>=2.6`
