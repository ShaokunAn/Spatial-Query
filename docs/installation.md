# Installation

## Requirements

- Python >= 3.8
- A C++ compiler (for the bundled C++ extension)

## Install from GitHub

```bash
pip install git+https://github.com/ShaokunAn/Spatial-Query.git@main
```

## Install in development mode

```bash
git clone https://github.com/ShaokunAn/Spatial-Query.git
cd Spatial-Query
pip install -e .
```

## Dependencies

SpatialQuery requires the following packages (installed automatically):

- `anndata>=0.8.0`
- `pandas>=2.0.3`
- `scipy`
- `matplotlib>=3.7.5`
- `mlxtend>=0.23.1`
- `seaborn>=0.13.2`
- `scikit-learn>=1.3.2`
- `statsmodels>=0.14.0`
- `scanpy>=1.9.5`
- `pybind11>=2.6`
